## 2. 已确认的问题与证据

1. **关闭辅助项也停止了门控参数学习。** 原路由通过布尔比较和索引生成硬掩码，预测 MSE 对 `mask_moe.gate`、`mask_moe.noise` 的梯度为 None。权重为 0 的最佳模型中，这些参数与 seed=2021 的初始化逐元素相同；其他网络参数仍正常训练。因此“关闭辅助损失”不等于“保留一个能由预测误差学习的门控”。
2. **patch=16 时缺少多片段关系。** seq_len=16 下，每股只有一个 patch；每个节点的空间/时间/时空候选数为 **473/0/0**。历史仍进入嵌入，但时间和时空两类边为空。
3. **预测高度依赖近期平均收益。** 三组预测与过去 16 日平均收益的日截面 Pearson 相关均值分别为 **0.885、0.890、0.841**。内部归一化后会加回窗口均值，这是一条值得检验的机制，尚不能单凭相关性证明其为唯一原因。模型的 `use_RevIN=False` 只关闭可学习仿射参数；归一化仍然执行，`--use_norm 0` 当前也不会关闭它。
4. **简单误差基线尚未超过。** 同一测试集预测 0 的 MSE 为 **0.000402521**，过去 16 日均值基线为 **0.000428347**，都低于三组模型。零预测没有选股排序能力，其 IC 未定义，不能把它的任意并列排序用于选股成绩比较。
5. **后期训练没有带来验证改善。** 最佳 MSE 都在第 4～5 轮。以 0.005 为例，训练 MSE 从第 5 轮的 0.00028788 降至第 100 轮的 0.00020925，但验证 MSE 从 0.00125014 升至 0.00133997。表现符合后期泛化恶化；当前约 481 万参数，仅 990 个训练日期窗口，值得后续检查模型容量。

另外，0.05 和 0.005 两组完整预测数组的相关系数为 **0.99675**，说明仅把辅助权重降低十倍，输出变化很小。

不能只凭辅助损失数值大就断言其梯度一定占主导：在最佳模型、训练目标下标 200/600 的两个样本上，固定随机种子 99，测得“加权辅助梯度范数 / MSE 梯度范数”分别约 **4.04（0.05）/0.45（0.005）**。这是局部诊断，不代表整个训练过程。

## 3. 与 StockMixer 仍有哪些未对齐

- 两个本地项目的 SP500.npy 逐元素相同；保存的测试真实值与重新计算的下一日收益率逐元素相同，当前检查没有发现测试标签错位。
- TimeFilter 只输入收益率；StockMixer 输入五项行情特征，使用收益率 MSE 加排序损失。输入信息和优化目标不同。
- 当前 TimeFilter 边界为 1006/1259。本地 StockMixer/src/train.py 仍是 NASDAQ 默认配置，边界为 756/1008，没有专门覆盖 SP500；不能仅改市场名就当作同协议对照。截图的实际运行配置不能由这份默认脚本反推。
- 训练与验证收益波动不同：零预测 MSE 分别为 0.00026860 / 0.00119490。因此不能仅凭验证误差大于训练误差就断定过拟合；应看固定验证集随轮次的变化。

## 4. 下一步：先做 patch 的单因素实验

暂以验证 MSE 最低的辅助权重 0.005 为参考，比较 patch=16 和 8。两组统一 batch=4，以控制显存；不要将 batch=4 的新实验直接视作与旧 batch=32 的单因素比较。其余配置保持不变。

```powershell
# 在 TimeFilter 项目目录、timefilter 环境下运行
python scripts/run_financial.py --dataset SP500 --batch-size 4 --moe-aux-weight 0.005 --patch_len 16 --financial_seed 2021
python scripts/run_financial.py --dataset SP500 --batch-size 4 --moe-aux-weight 0.005 --patch_len 8 --financial_seed 2021
```

patch=8 时每股有两个片段，可检验时间/时空候选不再为空后的表现。两组均使用当前 100 轮、相同学习率与验证 MSE 选模；先比较验证指标，不用测试结果选择参数。确认方向后再用相同的一组种子复验。

后续按顺序检查：较小模型容量 → IC/RankIC 验证选模 → 同划分重跑 StockMixer。五特征输入、排序目标或可微路由属于更大范围改动，当前未实施。
